# Функционал тексерісі — 2026-11-05

Табылған қателер түзетіліп, Android жергілікті сервермен байланыстырылды.
Бұрынғы жұмыс көшірмесіндегі өзгерістер сақталды. GitHub-қа жариялау жасалған жоқ.

## Түзетілген қателер

1. Polling UPDATE оқиғасы бос объект беріп, тапсырыс экранын бұзатын. Енді нақты
   жаңа/ескі жол және INSERT/UPDATE/DELETE түрі беріледі; unsubscribe кеш келген оқиғаларды тоқтатады.
2. Телефондағы `127.0.0.1` компьютерге қосылмайтын. LAN IP таңдау, тіркелу URL,
   CORS және сервер жасаған фото сілтемелері бір мекенжайға келтірілді.
3. Желілік қате GPS-ті біржола тоқтататын. Уақытша желі қатесі мен қолжетімділіктің
   жойылуы ажыратылды; рұқсат/смена/тапсырыс аяқталса GPS тоқтайды.
4. Expo Go-да фондық қызмет жоқ кезде GPS басталмайтын. Ашық қолданбада жұмыс істейтін режим қосылды.
5. Кірудің ескі Promise.race timeout-ы сұрауды тоқтатпайтын: кеш жауап күтпеген
   авторизация жасай алатын. Енді сұрау AbortController арқылы тоқтатылады.
6. Сервер қолжетімсіз кезде мобильді қолданба сессияны жоғалтқандай көрінетін.
   Байланыс қатесі және қайта қосылу экраны қосылды.
7. Android компаниясы клиент келісімінсіз тапсырысты қабылдай алатын.
   Баға ұсыну және клиент растауы SQL транзакцияларына көшірілді; веб пен Android ортақ ережені қолданады.
8. `create_order_with_bonus` динамикалық RPC рұқсат тізімінде жоқ еді.
   Бонусты тапсырыс жасау және клиент растағаннан кейін бір рет есептен шығару тексерілді.
9. Android бонус «автоматты жұмсалады» деп көрсеткенімен, сұрауда бонус жіберілмейтін. Түзетілді.
10. Компания клинерге төлемді алдын ала көрсетсе, комиссия есептелмейтін.
    `finances_finalized_at` қосылды; компанияның келісілген команда төлемі сақталады.
11. Карта төлемі `pending` тапсырыс аяқталғанда қате беретін. Енді тапсырыс аяқталады,
    төлем расталғанға дейін қаржылық финализация орындалмайды.
12. Ұсынылған бағаны күтудегі тапсырысты Android арқылы отмена жасау мүмкін емес еді.
    `offered` отменасы қосылды; отменада жұмсалған бонус бір рет қайтарылады.
13. Сервер өткен күнге немесе бөтен фотоға тапсырыс қабылдай алатын.
    Уақыт пен пайдаланушы жүктеген фотоға SQL тексерісі қосылды.
14. Android құпиясөз қалпына келтіру сілтемесін ашпайтын. Native маршрут пен deep link қосылды.
15. Expo SDK-ға сәйкес келмейтін React Native/AsyncStorage нұсқалары тураланды.
16. Android-та фото жүктеу ерекшелігі болса, батырма жүктелу күйінде қалатын. try/catch/finally қосылды.
17. Мобильді реферал сілтемесі ескі сыртқы доменге жіберетін. Жергілікті веб мекенжайы қолданылады.
18. Қолданбада дау ашу батырмасы болмаған; SQL RPC мен Android формасы байланыстырылды.

## Тексеру нәтижелері

- 11 Node тесті + 9 validation тесті: **20/20**.
- TypeScript және ESLint: өтті.
- Next.js production build: өтті.
- Android prebuild: өтті; manifest-те камера/GPS, foreground service және жергілікті желі конфигурациясы бар.
- Android Hermes bundle: өтті.
- Expo dependency check: өтті.
- LAN API, Android manifest/bundle URL және CORS: 4 тексеріс өтті.
- Вебтің ашық/қорғалған маршруттары, admin login, CSRF және admin тіркеуге тыйым: 17 тексеріс өтті.

Бизнес-сценарийлер: клиент/компания/клинер тіркелуі, ауысым, тікелей және компания
тапсырысы, бағаны растау, командаға тағайындау, GPS құпиялығы, статус ауысулары,
қолма-қол/карта pending, комиссия, пікірдің қайталанбауы, бонус/қайтарым,
дау ашу, парольді қалпына келтіру, сессияны қайтару, файл қауіпсіздігі және база тұрақтылығы.

## Нақты шектеулер

Бұл барлық ықтимал сценарийдің қатесіз екеніне кепіл емес. Нақты Android құрылғысы
қосылған жоқ; камера, батарея үнемдеу, экран бұғатталуы және фондық GPS құрылғыда
сыналған жоқ. APK жасауға Java/Android SDK жоқ; Expo аккаунты арқылы EAS signing
орындалған жоқ. Банктік төлем, SMS, SMTP, push және сыртқы картографиялық сервис
нақты провайдерлермен тексерілмеді. Әкімші шешімдері мен барлық қаржылық
қайтарым нұсқалары толық end-to-end сценарийлермен қамтылмаған.
