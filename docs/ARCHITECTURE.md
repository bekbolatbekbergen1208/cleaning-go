# Архитектура локальной версии

`apps/admin` — Next.js, PWA, кабинеты и серверные действия.
`apps/mobile` — Expo Router, мобильные кабинеты и геолокация.
`packages/local-client` — общий HTTP-клиент с запросами, сессиями, файлами и опросом изменений.
`local/server.mjs` — самостоятельный Node.js API.
`local/database.mjs` — PostgreSQL через PGlite, журнал и запуск миграций.
`local/query.mjs` — параметризованные запросы и разрешённые RPC.
`local/migrations` — таблицы, SQL-функции, триггеры, RLS.

Приложения обращаются к HTTP API. API хранит PostgreSQL в `.local-data/db` и
исполняет запросы в транзакции с ролью `anon`, `authenticated` либо `service_role`.
Идентификатор пользователя берётся из проверенной серверной сессии. Политики RLS
и SQL-функции сохраняют границы пользователей, компаний и сообществ.
Внешний ввод не подставляется в SQL как значение: используются параметры;
идентификаторы и операторы проходят проверку. Системные схемы и внутренние функции
не доступны через API запросов.

Серверные кабинеты используют `LOCAL_SERVICE_KEY`; этот ключ нельзя включать
в `NEXT_PUBLIC_*`, `EXPO_PUBLIC_*` или клиентский код. Действия с сервисным клиентом
по-прежнему обязаны проверять роль и принадлежность сущностей в Next.js.

Пароли хешируются scrypt с отдельной солью. Сессии — случайные 256-битные токены;
в базе хранится SHA-256 токена. Срок сессии — 7 дней. Выход отзывает токен,
смена пароля отзывает все сессии. Заблокированный профиль не проходит авторизацию.
Восстановление пароля использует одноразовый токен на час; локальное письмо
записывается в `.local-data/mail` и не возвращается анонимному вызывающему.

Файлы лежат на диске; метаданные защищены RLS. Загрузка требует папку пользователя,
разрешённый MIME-тип и размер. Чтение — через подписанную ограниченную по времени ссылку.
Серверные страницы подписывают фото заказов только после проверки участника заказа.

Изменения заказов, координат и уведомлений клиенты получают опросом раз в 3 секунды.
Каждый опрос проходит обычную авторизацию и RLS; постоянного внешнего Realtime-сервиса нет.
Бизнес-правила цены, финансов, отзывов, смен и бонусов исполняются в PostgreSQL.

PGlite открывается только процессом API. Административный CLI, резервное копирование
и ручные операции с файлами базы выполняются при остановленном API.
